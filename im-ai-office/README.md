# IMAI · 应用主目录

> **本目录是应用代码**。项目介绍、架构说明、快速上手请看[仓库根目录 README](../README.md)。

- `backend-ts/` — Hono + Drizzle 后端单体（TypeScript）
- `frontend-ts/` — 原生 TypeScript 前端（esbuild，无框架）
- `electron/` — Electron 桌面壳
- `web/` — 前端构建产物
- `docs/specs/` — 功能设计 Spec；`docs/plans/` — 执行计划
- `scripts/` — 运维与部署脚本

开发与贡献流程见 [CONTRIBUTING](../.github/CONTRIBUTING.md)。
