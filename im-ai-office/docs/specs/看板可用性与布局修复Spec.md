# 看板可用性与布局修复 Spec

> 日期：2026-09-01 · 类型：UX 改进（评估报告 P0-P1 项） · 范围：纯前端（index.html/app.js，双端同步）

## 背景

2026-08-31 使用者视角评估指出三类问题：① 待确认任务无限期堆积、无逾期感知；② 状态指示器盖住看板页签、窄窗口聊天区塌缩为 0；③ 测试入口外露。

## 变更

| 项 | 文件 | 说明 |
|---|---|---|
| 截止时间具体化 | app.js `renderTaskCard` | `deadline_at` 存在时换算为 `M/D HH:MM` 追加显示（如「周五前 · 9/4 23:59」），相对文案与真实时刻并排，解析误差自然显形 |
| 逾期标红 | app.js + index.html | 截止已过且未取消 → 卡片 `overdue` 样式（红边/红底）+ 截止文字红色 + 「已逾期」标签 |
| 老化排序 | app.js `loadTasks` | 待指派/待确认按 `deadline_at` 升序（无日期沉底），越临期/越逾期越靠前，旧任务不再沉底被遗忘 |
| 状态球移位 | index.html | `.backend-status` 从 top 改 bottom（右下角），不再遮挡看板页签；`.board-columns` 加 `padding-bottom:72px` 防内容被压 |
| 窄窗口兜底 | index.html | `.chat { min-width:260px }`；`@media (max-width:860px)` 隐藏看板面板（聊天优先，桌面默认窗口宽不受影响） |
| 测试入口收敛 | app.js + index.html | `.sim-toggle` 默认 `display:none`；`?debug=1` 或 `localStorage.imai_debug=1` 才显示 |
| 缓存击穿 | index.html | 上轮遗留：`app.js?v=20260831`（沿用） |

## 验证

- 浏览器实测：5 个页签完整可见；3 张过期卡（#22/#13/#7）红边 + 「已逾期」；#39 显示「明天下班前 · 9/1 23:59」；待确认列表逾期项排最前；模拟消息入口不可见。
- 注意：`#22「明天上午十点」deadline_at=8/31 23:59` 暴露既有时刻点解析缺口（"明天上午十点"应解析为次日 10:00 而非当天末尾）——交接文档 D3② 已登记，本次不修。
- 回归：pytest 全量三轮分别 95/104/105 passed，各有 1 例不同的环境性时序失败/SQLite 锁（交接文档 #10 已登记的已知抖动，单跑全过）；本轮无 Python 改动。
