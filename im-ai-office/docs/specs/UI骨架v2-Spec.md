# UI 骨架 v2 设计 Spec（含双主题）

> 2026-09-03 · 基于 A/B/C 风格对比 + 市面同类产品调研（钉钉 AI 小钉/飞书智能伙伴/Slack AI/MS Copilot）+ 子代理对抗性评审修订
> 状态：待实施 · 纯前端改造（frontend-ts/src/app.ts + static/index.html），后端 API 零改动

## 1. 设计原则（三条铁律）

1. **卡片是 AI 的统一语言**：AI 的一切产出（确认卡/提醒卡/纪要卡/汇总卡/挖掘候选卡）共用同一卡片结构——AI 头像 + 标题 + 类型徽标（右上角）+ 内容 + 操作按钮。用户只需学会一件事："看到 AI 卡片 = AI 找我做事，底部按钮 = 我的回应"。
2. **AI 三态规则**（每个 AI 功能必须自问属于哪一态）：
   - 主动态：有需要人处理的事 → 导航"任务"角标（待确认数）+ "聊天"角标（未读消息数，与任务角标分色）+ 卡片推送到人
   - 工作态：AI 正在识别/生成 → 轻量状态提示（聊天头部"AI 正在旁听…"呼吸灯 / 顶栏 pill 加载态），不弹窗
   - 静默态：无事发生 → AI 完全隐形，不为刷存在感说话
3. **单一事实源**：任务状态机（pending_confirmation → confirmed/rejected/done/cancelled）是唯一权威。确认卡在聊天与任务页双入口渲染同一状态，任一入口操作后两处即时收敛（SSE 已有 task 事件，复用）；已终结的确认卡在聊天流原地变灰留痕（不删除，保留"AI 做过什么"的透明度）。

## 2. 骨架

```
┌──────┬────────────────────────────────────┐
│ 导航  │ 顶栏：视图标题 · AI 状态 pill(仅主动/工作态) │
│ 聊天  │      · 搜索(预留) · 主题切换 · 用户    │
│ 任务  ├────────────────────────────────────┤
│ 审批  │  主内容区（按导航切换）                 │
│ 记忆  │                                    │
│ 汇总  │                                    │
│ ──── │                                    │
│ 权限  │                                    │
│ 设置  │                                    │
└──────┴────────────────────────────────────┘
```

- 导航栏 64px，SVG 线性图标（随主题变色，禁用 emoji）+ 11px 文字标签 + title tooltip；hover/active 态；角标：任务=待确认数（红底白数字）、聊天=未读消息数（同规格，位置区分）
- 旧版权限 tab 保留为独立导航项"权限"（评审 P2-9：不并入设置，避免功能回退争议）；设置页含：默认落地页选择（聊天/任务，默认聊天）、主题（跟随系统/浅/深）

## 3. 视图定义

### 3.1 聊天（默认落地页）
- 结构与功能 = 旧版聊天全量：会话列表 + 消息流 + 底部输入框；群聊/单聊/AI 助手会话行为不变
- AI 助手 = 置顶会话（固定第一位，带"置顶"标识），Slack Assistant 模式
- 聊天头部右侧：工作态呼吸灯（仅 AI 正在处理时显示）
- 确认卡出现在消息流内（AI 助手会话与来源群），操作后原地变灰："✓ 已确认"（留痕）

### 3.2 任务工作台
- 布局：顶部"需要你处理"横排区（当前用户相关的确认卡+逾期提醒卡，按 assignee 过滤；无则隐藏横排，不渲染空卡片）→ 下方看板列
- **看板列 = 互斥流程状态**（评审 P0-2）：待确认 / 进行中（已确认） / 已完成（含 done）；已取消不入列（可在汇总查）
- 逾期是**卡片属性**非列：红色"已逾期"标签 + 列内排序置顶（评审 P0-2）
- 横排确认卡操作按钮：确认 / 驳回 ▾（原因选择器，沿用 G14）/ 改负责人（弹行内编辑）；双入口状态收敛见 §1-3
- 空态：新团队无任务时显示引导卡（"在任意群里安排一件事试试，我会自动记下来"）

### 3.3 审批 / 汇总 / 权限
- 内容 = 旧版对应 tab 全量迁移，套新主题；审批页明确与任务确认卡的边界（审批 = 高风险动作 M3 审批流；确认 = 任务归属确认），页首各一句说明

### 3.4 记忆（评审 P1-8 修订版）
- 顶部横幅：中性仪表 + 克制拟人——"团队记忆 · 认识 N 位同事 · M 条术语 · 上次更新 {时间}"；紫蓝渐变仅此一处大面积使用
- "最近学到"列表保留但**中性表述**（"9-1 驳回『明天上午去演出』→ 此类自发活动不建任务"），删"越来越懂你们"类表演文案
- **每条记忆可操作**：纠正（行内编辑，走 PATCH /api/term）、删除（DELETE，成员可纠正、仅管理员可删除——沿 RBAC）、点击展开溯源（引用来源消息，二期）
- 术语管理功能（增删改）全量保留

## 4. 主题系统

- CSS 变量双套（`:root[data-theme=light|dark]`），全部颜色经 token，禁止散落硬编码（现状 18 种散色收敛为：bg/panel/border/text/muted/accent/ok/danger + soft，9 个 token）
- 深色主题对比度修正（评审 P1-7）：主按钮深色下用纯色 --accent（#9a8cff 级），渐变只保留在 AI 头像/logo/记忆横幅等非文字载体；深色 --muted 提亮至 #9ba1b0；卡片层级靠边框+明度差，不靠阴影
- 主题三选：跟随系统（prefers-color-scheme）/ 浅 / 深，存 localStorage

## 5. 响应式底线（评审 P1-6）

- AI 卡 meta 加 flex-wrap；卡片 max-width 用 `min(480px, 100%)`；按钮超 2 个收敛为"主操作 + ⋯"
- 看板 <1100px 横向滚动（列阴影提示）；聊天+看板双栏 <900px 自动只显示单栏 + 顶部切换
- 删除 mock 的 zoom hack，不用整体缩放

## 6. 默认落地页与迁移（评审 P1-4/P2-14）

- 默认落地页：**聊天**（尊重 IM 肌肉记忆），设置可切"任务工作台"；记住用户上次停留视图（本次会话内）
- 首次进入新版：一次性"新版变化"提示条（导航栏结构说明 + 默认落地页在哪改），可关闭不再出现

## 7. 明确不做（backlog）

Ctrl+K 全局搜索、键盘快捷键导航、记忆溯源抽屉、移动端、灰度开关（10 人团队全员切换 + 一句话反馈即可）

## 8. 验收清单

1. tsc 0 错误、vitest 全绿（前端纯 UI 改造不应破坏任何 G 守卫）
2. 聊天全功能回归：收发消息/历史/SSE/确认卡/口头完成 —— 与旧版行为一致
3. 双入口状态收敛：聊天点确认 → 任务页卡片即时消失（SSE）；反之亦然
4. 任务角标 = 待确认数、聊天角标 = 未读数，实时更新
5. 深浅主题切换全视图无对比度硬伤、无 emoji 图标
6. 记忆页每条术语可改可删（成员纠正/管理员删除）
7. 看板列状态互斥、逾期为标签且置顶排序
8. 真机（已安装应用）截图验收 + 同步 resources/backend/web
