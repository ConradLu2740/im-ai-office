**Tech Stack:** Node 26 / TypeScript 5 / Hono 4 / Zod 3 / Drizzle 0.44.x / esbuild / Vitest 2 / Electron 33+ / PostgreSQL 16（Windows 原生，C:\imai\pgdata）

**全局约束（每个 Task 都适用）：**
- 工作目录：仓库根 `im-ai-office/`；路径均相对此根
- 测试库：`imai_test`（`postgresql://imai:imai_secret@127.0.0.1:5432/imai_test`）；生产：`imai`

**main.ts 要点（完整实现骨架）：**

```ts
import { app, BrowserWindow, Tray, Notification } from "electron";
import { spawn } from "node:child_process";
import path from "node:path";

let backendProc: ReturnType<typeof spawn> | null = null;
let restarts = 0;

function backendArgs(): string[] {
  // 开发：tsx watch；生产：dist/index.js（esbuild 产物，依赖内联）
  return app.isPackaged
    ? [path.join(process.resourcesPath, "backend", "dist", "index.js")]
    : ["--import", "tsx", "src/index.ts"];
}
function backendCwd(): string {
  return app.isPackaged
    ? path.join(process.resourcesPath, "backend")
    : path.join(app.getAppPath(), "backend-ts");
}
function startBackend(): void {
  backendProc = spawn(nodeExecutable(), backendArgs(), {
    cwd: backendCwd(),
    stdio: ["ignore", "inherit", "inherit"],
  });
  backendProc.on("exit", (code) => {
    backendProc = null;
    if (!app.isQuitting && restarts < 5) {          // crash 退避重启
      setTimeout(() => { restarts++; startBackend(); }, 1000 * 2 ** restarts);
    }
  });
}
// 生命周期：app.on("before-quit") 杀进程树（Windows 用 taskkill /pid <pid> /T /F）
// 端口预检：main 启动时若 8000 已被占且是孤儿 node → taskkill 清理（交接文档「应用关了但进程还在」先例）
// 托盘：Tray + 未读角标（数据源：轮询 /api/ai_dm unread + /api/tasks pending）
// 通知：Notification（SSE 桥：渲染层收到 reminder/ai.card/task_created → IPC → 主进程 Notification）
// 自启：app.setLoginItemSettings({ openAsHidden: true })；**同时 schtasks /delete "IMAI Autostart" 与 "IMAI Backup" 保留**
```

**Step 1:** 实现上述模块；preload 只暴露 `invoke(channel, payload)` 白名单（api_call 平移：主进程 fetch 8000，UTF-8 原生无编码问题）。

> 开工前重审：生产 audit schema 漂移对齐方案（Task 1.1）有 DB 变更，先做 imai 库备份。

### Task 1.1：audit schema 漂移对齐（一次性 SQL 迁移）

生产 audit 表 = created_at + JSONB；代码 schema = ts + TEXT。**决策：统一到代码 schema**（新代码已按 ts 运行时探测，对齐后删除探测分支）。

```sql
-- 幂等：重跑安全（评审预演 ⑨）
ALTER TABLE audit ADD COLUMN IF NOT EXISTS ts TIMESTAMPTZ;
UPDATE audit SET ts = created_at WHERE ts IS NULL AND created_at IS NOT NULL AND ts IS DISTINCT FROM created_at;
ALTER TABLE audit ALTER COLUMN detail TYPE TEXT USING detail::text;
```
（重跑时 UPDATE 零行、ALTER 对已是 TEXT 的列为 no-op）

**Files:** Create: `backend-ts/drizzle/migrations/0001_audit_align.sql`（手工迁移，drizzle-kit custom）
**验证:** `SELECT column_name FROM information_schema.columns WHERE table_name='audit'` 含 ts 且 detail 非 jsonb；audit_recent/stats.ts 的运行时探测分支可简化（保留返回值接口不变）。

### Task 1.2：drizzle-kit pull 基线

**Files:** Create: `backend-ts/src/db/schema.ts`（pull 生成后人工审校：int8 列 `bigint({ mode: "number" })`、jsonb 用 `jsonb().$type<...>()`）
**Step:** `npx drizzle-kit pull`（指向 imai 库）→ **人工逐表比对**（评审 B：pull 有 JSONB 边界 bug，用 0.44.x 稳定版）→ `npx drizzle-kit generate --custom` 生成空基线把迁移历史记入 `__drizzle_migrations`（评审 B：否则后续 generate 会试图重建已存在的列）。
